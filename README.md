# Libri — serie "Sirena Blu"

Albi illustrati per bambini di 3–6 anni sul soccorso, scritti da un autista soccorritore di San Marino.

- `index.html` — kit del libro 1: storia, personaggi, guida e prompt per le illustrazioni (si apre anche su GitHub Pages)
- `CLAUDE.md` — contesto condiviso per gli agenti (Munder Difflin / Claude Code)
- `bibbia/` — personaggi, schede, stile e regole di scrittura
- `libri/` — testi e storyboard
- `prompt-illustrazioni/` — prompt per Gemini
- `agenti/` — istruzioni dei cloni
- `LEGGIMI.md` — come usare la cartella con Munder Difflin
